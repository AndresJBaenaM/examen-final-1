# 🐉 DragonDex

Aplicación web desarrollada con **React + TypeScript + Vite**  que consume la **PokéAPI** para mostrar dragones (Pokémon tipo dragón).  
Incluye búsqueda, un detalle de cada dragón y un sistema de favoritos.

## Características
- Listado de dragones con imagen y tipos.
- Barra de búsqueda para filtrar resultados.
- Sistema de favoritos con persistencia en contexto.
- Estilos modernos usando **TailwindCSS**.

## ⚙️ Instalación
1. Clona el repositorio:
   git clone https://github.com/AndresJBaenaM/examen-final-1
2. npm install en bash
3. npm run dev
